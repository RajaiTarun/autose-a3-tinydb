# ADR-003: Hand over artifact files, the code and 5-line notes; never conversations
**Status:** Accepted
**Date:** 2026-11-21

## Context
Each agent needs enough context to do its job, but extra context costs usage and destroys independence.
The assignment requires that the Reviewer never sees the implementer's reasoning.

## Decision
Each worker receives **the earlier artifacts as files, a shallow checkout of the code (no git history) and
a 5-line "notes for the next stage"** from the agent before it. Notes flow Spec → Design → Implementer.
**The Tester gets the Design notes but not the Implementer's notes.** The Reviewer gets **only** the issue,
the PR diff and the code at the PR head. No conversation is ever passed on.

## Alternatives considered
- *Artifacts only:* the most independent, but the next agent loses the "why" (e.g. assumptions made in the spec).
- *Full conversations:* the most context, the heaviest on usage, and no independence.

## Consequences
- Positive: small prompts; the Tester writes tests from the spec; the Reviewer stays independent.
- Negative: notes can carry a wrong assumption forward; 5 lines may be too short for complex issues.
- No git history: the seeded defects (experiment setup) cannot be found in `git log`.
