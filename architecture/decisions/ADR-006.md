# ADR-006: Haiku 5.5 for every role except the Implementer (Sonnet 5.5)
**Status:** Accepted
**Date:** 2026-11-21

## Context
All model calls run on one Claude Pro subscription token (usage credits off, so $0 extra), and its usage
limit is shared with the author's other work. Usage is the binding constraint, not money. The goal is to
be as efficient as possible, as a step toward trying small language models (SLMs) for such pipelines.

## Decision
**Haiku 5.5** for Spec, Design, Tester, Reviewer and the spec judge; **Sonnet 5.5** only for the
Implementer, the one stage where code quality decides success. The Reviewer is therefore a different
model from the Implementer.

## Alternatives considered
- *Sonnet 5.5 for all roles (the initial choice, dropped before any code was written):* better quality, but roughly twice the usage.
- *Haiku 5.5 for all roles:* the least usage, but weaker code means more retries, which may cost more in total.
- *Opus 5.5 for the Reviewer:* the strongest independent check, but the heaviest on the limit.

## Consequences
- Positive: about half the usage of Sonnet-for-all; text-only stages need less ability.
- Negative: Haiku may write weaker specs, tests and reviews; the Reviewer may miss subtle bugs. Measured by the seeded PRs (experiment A).
