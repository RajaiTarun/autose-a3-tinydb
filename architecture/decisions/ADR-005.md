# ADR-005: Agents get SDK built-in tools scoped per role and no GitHub access
**Status:** Accepted
**Date:** 2026-11-21

## Context
Issue text is untrusted, and every tool an agent holds is something an injected instruction could misuse.

## Decision
Agents use **Claude Agent SDK built-in tools only**, set per role with `allowed_tools`: Read/Grep/Glob for
all; Edit/Write for the Implementer and Tester; Bash restricted to `pytest`/`python` for those who run
code. **No agent receives a GitHub token**: the orchestrator removes `GH_TOKEN`/`GITHUB_TOKEN` from the
agents' environment, and only plain code (orchestrator, release.py, review.py) calls `gh`.

## Alternatives considered
- *Agents call the `gh` CLI:* more autonomous, but every agent then holds a token that injected text could use.
- *GitHub MCP server:* standard, but a larger tool surface than these agents need.

## Consequences
- Positive: the worst an injected instruction can do is edit files on a throwaway branch, which the checks and the Reviewer then see.
- Negative: more plumbing code in the orchestrator.
