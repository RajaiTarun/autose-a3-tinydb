# ADR-004: Keep state as files on the PR branch
**Status:** Accepted
**Date:** 2026-11-21

## Context
State must survive between stages, between review rounds (separate runs) and across restarts, and anyone
must be able to follow a run on GitHub.

## Decision
`.autose/issue-N/` holds `state.json` (stage, attempts, round, token usage) plus every artifact and note. It
is **committed to branch `autose/issue-N`** after each stage and also uploaded as an Actions artifact. A
restart or review round reads `state.json` and resumes from the last passed stage.

## Alternatives considered
- *Actions artifacts only:* they expire (90 days) and are awkward to browse.
- *JSON in PR/issue comments:* very visible, but fragile to parse, and anyone who can comment can interfere.

## Consequences
- Positive: everything is versioned and linkable; the PR shows the artifacts next to the code.
- Negative: the PR diff includes `.autose/` files, which the Reviewer must ignore (it is told to); one extra commit per stage.
